# Contributing to Ollama-Go

First off, thank you for considering contributing to Ollama-Go! It's people like you that make open source such a great community.

## Where do I go from here?

If you've noticed a bug or have a feature request, [make one](https://github.com/SamyRai/ollama-go/issues/new)! It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

If you have a general question, feel free to ask in the [Discussions](https://github.com/SamyRai/ollama-go/discussions) section.

## Fork & create a branch

If you're ready to start coding, fork the repository and create a new branch from `main`. A good branch name would be something like `fix/my-bug` or `feat/my-new-feature`.

## Get the code running

This project uses Go. You'll need to have Go installed on your machine. You can find installation instructions [here](https://golang.org/doc/install).

Once you have Go installed, you can run the tests to make sure everything is working as expected:

```bash
go test ./...
```

## Make your changes

Make your changes to the code. Please make sure to follow the existing code style.

## Test your changes

If you've added new functionality, please add tests for it. If you've fixed a bug, please add a test that demonstrates the bug and that your fix resolves it.

## Commit your changes

Once you're happy with your changes, commit them with a descriptive commit message. We follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.

## Open a pull request

When you're ready, open a pull request. Please make sure to fill out the pull request template with as much detail as possible.

Thank you for your contribution!
